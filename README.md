📌 Project Overview
This is a complete *End-to-End Data Analysis Project* on OLA ride booking data. The project involves data extraction, data cleaning, data transformation, and data visualization to generate actionable business insights from a large ride-booking dataset.

The project is divided into two major parts:
- *SQL Analysis* — Querying and extracting insights from raw booking data
- *Power BI Dashboard* — Interactive visualizations for business intelligence reporting

🎯 Objective

To analyze OLA ride booking data and answer key business questions related to:
- Booking status and cancellation patterns
- Revenue generation and payment methods
- Customer and driver ratings
- Vehicle type performance
- Ride distance and volume trends
